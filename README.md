# Ajay AVC Helper

**A simple time-saving browser helper for HindiGeetMala and Any Video Converter users.**

## 🎯 What is Ajay AVC Helper?

Ajay AVC Helper is a lightweight Tampermonkey userscript that helps users quickly collect all song-page links from a HindiGeetMala movie page.

Instead of copying song links one by one, the helper finds the available song links on the movie page and copies them all to the clipboard with one click.

The copied links can then be used with **Any Video Converter**.

## ✨ Features

* 📋 Copy all song links with one click
* 🔗 Automatically finds HindiGeetMala song-page links
* 🚫 Removes duplicate links
* 📋 Copies links directly to the clipboard
* ⚡ Saves time when working with multiple songs
* 💻 Works in supported desktop browsers with Tampermonkey
* 🔒 No account required
* ☁️ No cloud service
* 📢 No advertisements
* 💳 No subscription

## 🛠️ Requirements

You need:

1. A supported desktop web browser
2. Tampermonkey
3. A HindiGeetMala movie page

Any Video Converter is optional and is only needed if you want to use the copied links with it.

## 📥 Installation

### Step 1 — Install Tampermonkey

Install the Tampermonkey browser extension for your supported browser.

### Step 2 — Install Ajay AVC Helper

Open the `Ajay-AVC-Helper.user.js` file from this repository.

Tampermonkey should recognize the userscript and provide an option to install it.

Confirm the installation.

## ▶️ How to Use

1. Open a HindiGeetMala movie page.

2. Look at the top-right corner of the page.

3. Click:

   **📋 Copy Song Links**

4. The helper will find the song links on the page.

5. The links will be copied to your clipboard.

6. Open Any Video Converter and use the copied links.

That's it.

## 💡 Why was it created?

The idea came from a simple real-world problem:

Copying many song links individually takes unnecessary time.

Ajay AVC Helper was created to simplify that repetitive task.
